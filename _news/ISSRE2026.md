Our paper "KubeCap: A Framework for Capability Minimization in Kubernetes via Static Analysis and LLM-Assisted Rule Inference" is accepted at ISSRE 2026.

This work presents KubeCap, a framework that combines static analysis with LLM-assisted rule inference to minimize Linux capabilities for Kubernetes workloads, reducing unnecessary privileges while preserving functionality.
